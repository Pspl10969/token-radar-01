The board re-ranks live. The peer multiple is read off the snapshot's own traded protocols; these two weights are the model's judgement calls.

How the number is made

Implied value is this entry's own claim about a launch that has not happened, made from the snapshot's figures alone. It is not a prediction that a token will be issued, or when. A protocol is described as recording no token, never as having none: the snapshot is DefiLlama's record, and a record can lag the world. Farm plans are starting points, not advice; check a protocol's own page before moving funds, and never pay anyone a fee to claim an airdrop.
